# Keyboard Shortcuts

## File

| Action | Shortcut |
|--------|----------|
| New score | Ctrl+N |
| Open score | Ctrl+O |
| Save | Ctrl+S |
| Print | Ctrl+P |
| Quit | Ctrl+Q |

## Edit

| Action | Shortcut |
|--------|----------|
| Undo | Ctrl+Z |
| Redo | Ctrl+Y |
| Copy measures | Ctrl+C |
| Paste measures | Ctrl+V |
| Fill paste | Ctrl+Shift+V |
| Clear measures | Del |
| Delete measures | Ctrl+Del |

## View

| Action | Shortcut |
|--------|----------|
| What's this? | Shift+F1 |

## Score editor — mouse

| Action | Result |
|--------|--------|
| Left click on note line | Toggle default note head on/off |
| Middle click on note line | Cycle through available note heads |
| Right click on note line | Context menu (insert, delete, repeat...) |
| Right click on barline | Barline options |
| Double click on drum key label | Edit kit information |
| Double click on beat count | Edit measure count |
| Double click on repeat count | Edit repeat count |
| Double click on BPM marker | Edit BPM change |
| Double click on alternate ending | Edit alternate ending |

## Note head shortcuts

Each drum line has keyboard shortcuts for its note heads. The shortcuts
are shown in the **Head (Shortcut)** display at the bottom right of the
window when you hover over a drum line.

Default shortcuts are assigned alphabetically. You can customise them in
the **Drum Kit Editor** (**Score → Edit Drum Kit**).
