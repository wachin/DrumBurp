# MIDI Playback

DrumBurp plays MIDI sound through `pygame`. It does not use JACK, TiMidity,
Qsynth, or QtMultimedia directly.

---

## Requirements

On Debian, Ubuntu, and MX Linux, install the normal runtime dependencies:

```bash
sudo apt install python3-pyqt5 python3-pygame
```

`python3-pygame` is the package that DrumBurp uses for MIDI playback.

---

## How Playback Works

The MIDI playback code lives in `src/GUI/DBMidi.py`.

At startup DrumBurp imports `pygame` and `pygame.midi`, then initializes both
`pygame.midi` and `pygame.mixer`. It asks `pygame.midi` for the default MIDI
output device and opens it with `pygame.midi.Output`.

Short preview notes, such as the sound played when editing drum kit MIDI
settings or adding a note, are sent directly to that MIDI output device with
MIDI `NOTE_ON` messages on the percussion channel.

Full score playback works differently:

1. DrumBurp builds the score playback data internally.
2. It writes a complete MIDI file into memory with `exportMidi()`.
3. It loads that in-memory MIDI file with `pygame.mixer.music.load()`.
4. It starts playback with `pygame.mixer.music.play()`.

The **File -> Export MIDI** command uses the same internal MIDI writer, but saves
the generated bytes to a `.mid` file instead of handing them to
`pygame.mixer.music`.

---

## Playing Back a Score

- **MIDI -> Play Score** plays the whole score from start to finish
- **MIDI -> Loop Selected Measures** loops the selected measures
- **MIDI -> Play Selected Measures Once** plays the selection once
- **MIDI -> Mute MIDI** toggles note audio on/off while editing

To select measures, click and drag across them in the score editor.

---

## Exporting to MIDI

**File -> Export MIDI** saves the score as a `.mid` file that you can use with
any MIDI player or DAW.

This export does not require a working audio output device. If playback is
silent, exporting a `.mid` file is a useful way to confirm that DrumBurp is still
generating valid MIDI data.

---

## Troubleshooting

### No Sound

- Make sure `python3-pygame` is installed.
- Check that the operating system has an active audio/MIDI output device.
- Use **MIDI -> Refresh Device List** to re-scan for MIDI devices.
- Try **File -> Export MIDI** and open the `.mid` file with another MIDI player.
- JACK, Qsynth, or TiMidity can be useful as extra MIDI outputs on some Linux
  systems, but they are not required by DrumBurp itself.

### "Playback error -- There are inconsistent repeat markings"

Check your repeat barlines. Every repeat start must have a matching repeat end.
